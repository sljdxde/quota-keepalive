QKA Windows portable package

QKA.exe       Desktop app. Double-click to start the tray and main window.
QKA-cli.exe   Console build for task-run, doctor, serve, and other CLI modes.
bun.exe       Bundled adapter runtime.
adapters/     Bundled QKA adapters.

Keep these files together. QKA looks for bun.exe and adapters/ beside its own
executable.
