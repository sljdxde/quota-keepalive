# QKA UI 暗色可读性与菜单栏交互验收

日期：2026-10-30
分支：`codex/workbuddy-mvp-integration`

## 结论

- 主窗口、菜单栏面板和设置窗口统一为 Magpie 风格的冷灰背景、圆角卡片和语义状态色。
- 暗色提供近实色卡片与高对比文字，不再依赖过度透明的背景；正文、次要文字、弱文字和状态文字均达到 4.5:1 以上。
- 主窗口使用品牌绿色方块标记、居中分段导航、冷灰渐变背景和 1240×820 初始尺寸。
- 菜单栏面板保持单层精简信息，不再复制主窗口导航；点击「打开 QKA」后面板隐藏，主窗口显示。
- 菜单栏面板固定为 392×520，空状态收为紧凑卡片，底栏只保留账号数、巡检、打开 QKA 和退出。
- MVP 应用页和面板只展示当前已接通的 WorkBuddy CN，不再暴露尚未闭环的 Qoder 和豆包工作。
- 本轮没有使用真实账号、真实登录文件或腾讯网络；账号闭环仍以受控测试记录为准。

## 未覆盖

- 当前系统外观为浅色；暗色完成了 token 对比度计算、静态 CSS 检查和 Wails 实际浅色窗口截图，没有切换全局系统外观。
- 没有真实账号数据下的长文本、多账号和失败状态截图；这些场景的自动化状态测试仍由账号闭环验收覆盖。
- 没有在旧版 macOS 或 Intel 架构上实测新窗口样式。
- Windows 已验证交叉编译、PE GUI 类型与图标资源；真实 Windows 任务栏、托盘和安装目录仍未在 Windows 真机验收。

## 范围边界

- 命令、模块路径、配置目录、数据库名、Keychain service 和 MCP 配置键继续使用小写 `qka`；仅面向用户的品牌与文案统一为 `QKA`。
- 固定 8 个 MCP 工具未改；本轮只调整 GUI 视觉与窗口交互。
- 不触碰未跟踪的 `packages/` 目录。
